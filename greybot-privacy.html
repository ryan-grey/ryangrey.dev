greyBot

Privacy Policy

Last updated 31 August 2026

greyBot is a Discord app that announces a World of Warcraft guild's first Heroic boss kills and posts a summary of raid nights. It is operated by Ryan Grey. This page describes exactly what it stores, where that data comes from, and how long it is kept.

The short version. greyBot stores no Discord personal data. It records no Discord user IDs, no usernames, no message content, and nothing about who uses its commands. What it does store are World of Warcraft character names, taken from raid logs that are already public.

What it stores

  • World of Warcraft character names, read from public Warcraft Logs reports. These are used to record who took part in a guild's first kill of a boss, and to work out which of the guild's raid teams filed a given report.
  • Raid progress state — which bosses have been announced, how many are dead, and whether the tier's Ahead of the Curve has been posted. This is what stops the same kill being announced twice.
  • Operational state — timestamps, raid and boss identifiers, and a record of whether the app can still reach Discord.

What it does not store

  • Discord user IDs, usernames, avatars or profile data.
  • Message content, channel history, or anything read from a server's messages. greyBot does not read messages and has no permission to.
  • Any record of who invokes its /progress command. The command is answered from a cached progress snapshot; the requester is not logged or retained.
  • Email addresses, IP addresses, payment details, or analytics of any kind.

Where the data comes from

greyBot reads from three public sources and writes to one place. It queries Warcraft Logs for which bosses died and when, Raider.IO for guild progress and realm rank, and Blizzard's public game data API for boss artwork. It posts to a single Discord channel through a webhook. No data is sent to those three services beyond the queries needed to read from them.

How long it is kept

Raid state and character names are kept for as long as the app runs for that guild, because the whole purpose of the record is to remember that a boss was already announced. There is no automatic expiry. To have a guild's stored data deleted, ask using the contact below and it will be removed.

Who can see it

The stored data lives in a private Amazon DynamoDB table in the operator's own AWS account, in the US East (N. Virginia) region. It is not shared with anyone, not sold, not used for advertising, and not used to train anything. The only place any of it becomes visible is in the messages greyBot posts to the guild's own Discord channel.

Children

greyBot is not directed at children and collects nothing that would identify one. It is intended for use in Discord servers, which require users to meet Discord's own minimum age.

Changes

If what the app stores changes, this page changes with it, and the date at the top is updated. There is no mailing list to notify, because greyBot collects no addresses.
